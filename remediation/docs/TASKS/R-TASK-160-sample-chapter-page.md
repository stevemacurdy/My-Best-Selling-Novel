## Implementation Requirements

### Page structure

Hero block at top:
- Heading: "What writing with My Best Selling Novel actually looks like"
- Subheading: brief framing — "This chapter was generated by the agent in about 12 minutes from a 3-paragraph outline. No human edits — verbatim agent output. Read it. Decide for yourself."
- CTA below hero: "Start Chapter One →" (mirrors hero/footer button)

Body:
- Render `content/sample-chapter.md` to HTML at build time (Next.js MDX or markdown plugin; use whichever already exists in repo via TASK-048). Wrap in `<article class="prose prose-invert max-w-[720px] mx-auto">` with brand-aware Tailwind typography overrides.
- Footer to the article: a small attribution line — "Generated by My Best Selling Novel from a 3-paragraph outline. No human edits."
- Closing CTA repeated below: "Like what you read? **Start Chapter One →**"

### Brand styling

- Page background `bg-brand-navy`
- Article body text `text-brand-white`
- Headings in Crimson Pro at scale defined by TASK-002 (h1: 48/56; h2: 36/44; etc.)
- Inline links `text-brand-gold hover:text-brand-goldDim`
- Block quotes (if used in sample) `border-l-4 border-brand-gold pl-4 italic`

### Content (operator writes)

The sample chapter content goes in `content/sample-chapter.md`. ~1,500-2,000 words. Operator commits original prose. Recommended framing for impact: a vivid first chapter from a single genre that matches operator's primary persona target (likely thriller, mystery, or literary fiction — high-engagement openers). The chapter should NOT be an obvious AI demo (no "the protagonist walked into the room"); it should be the kind of opening that makes the reader want chapter 2.

If operator opts to skip writing original prose at v1 ship: render a "Coming soon — expected [date]" placeholder with the same hero + footer structure intact, badged like the publish guides. Operator should set a follow-up task to write the prose within 30 days of launch.
